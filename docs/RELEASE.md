# MidiStudio 2.0.0 for Windows

Windows 10 이상 · x64. 통합 MidiStudio 데스크톱 앱입니다.

- MIDI/피아노 롤, 작곡 도우미, 오디오 녹음, VST3, 믹서와 커스텀 테마
- 플러그인 오토메이션, 루프 테이크·컴핑, 워프/타이밍 편집
- 그룹·리턴·센드·사이드체인 라우팅, 솔로와 MIDI 녹음 대기
- Oxygen Pro 연결 지원과 선택형 DAW LED 피드백

`MidiStudio-Setup-2.0.0.exe`를 이용해 설치합니다. 기존 프로젝트는 업데이트 전 별도로 백업하세요. 설치 없는 실행은 `MidiStudio-2.0.0.zip`을 사용합니다. 테마 파일은 앱 창에 끌어다 놓거나 개인설정에서 가져올 수 있습니다.

배포 파일은 코드 서명 인증서가 없는 개발 빌드입니다. `SHA256SUMS.txt`와 다운로드 출처를 확인하고 보안 기능을 끄지 마세요. 외부 플러그인과 오디오 드라이버는 포함하지 않습니다. 오디오 자동 채보는 지원하지 않습니다.
